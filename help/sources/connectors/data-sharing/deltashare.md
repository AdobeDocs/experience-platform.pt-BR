# [!DNL Deltashare]

Você pode usar o conector de origem [!DNL Deltashare] para estabelecer uma conectividade segura com [!DNL Databricks Delta Sharing] servidores e criar conjuntos de dados virtuais no Adobe Experience Platform. Com esse recurso, você pode consultar conjuntos de dados virtuais, inspecionar e mapear tabelas externas para esquemas do Experience Data Model (XDM) e aproveitá-los em aplicativos e serviços da Experience Platform. Com o [!DNL Deltashare], você pode evitar a assimilação física de conjuntos de dados, reduzindo, assim, a duplicação, os custos de armazenamento e a sobrecarga operacional.
