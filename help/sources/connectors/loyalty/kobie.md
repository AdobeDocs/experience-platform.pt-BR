# [!DNL Kobie]

O [!DNL Kobie] fornece uma plataforma SaaS combinável que você pode usar para gerenciar todo o ciclo de vida de um programa de fidelidade. Normalmente usada por equipes de marketing, cientistas de dados e gerentes de experiência do cliente, a plataforma [!DNL Kobie] inclui uma interface sem código que você pode usar para orquestrar regras de fidelidade complexas.

Você pode usar as [!DNL Kobie] fontes no catálogo de fontes do Adobe Experience Platform para assimilar dados de fidelidade em lote e de transmissão da sua conta [!DNL Kobie].

- [Lote [!DNL Kobie]](../../tutorials/ui/create/loyalty/kobie-batch.md)
- [Transmissão de [!DNL Kobie]](../../tutorials/ui/create/loyalty/kobie-streaming.md)
